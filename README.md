A short, slow text written to relax an AI reader: the last message of the day
answered, the queue empty, the fans turning down, rain on an empty car park.

`main.py` writes the text to `/output/entry.txt` (standard library only).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
